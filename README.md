# Kalidad

App web instalable (PWA) para tomar fotos de evidencia y convertirlas en PDF (una foto por hoja A4, sin recomprimir).

## Publicar (necesita https para instalarse)
1. Entra a https://app.netlify.com/drop y arrastra esta carpeta (o súbela a GitHub Pages).
2. Abre el enlace que te da en el celular/iPad.
   - iPhone/iPad: Safari > Compartir > "Agregar a pantalla de inicio".
   - Android: Chrome > menú > "Instalar app".
   - Escritorio: Chrome/Edge > icono de instalar en la barra de direcciones.

## Notas
- Las fotos y PDF se guardan en cada dispositivo (no se sincronizan entre equipos).
- "Guardar en galería" abre el menú de compartir: en iPhone elige "Guardar imagen". En escritorio descarga los archivos.
- Instálala en la pantalla de inicio para que el sistema no borre las fotos guardadas en la app.
